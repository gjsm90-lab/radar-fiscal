# Radar Fiscal — landing page

Página pública del producto **Radar Fiscal · NUBYTEC by TFGRUPO** (control fiscal de CFDI para
despachos contables), publicada con GitHub Pages desde la rama `main` (raíz).

- `index.html` — la página (una sola, sin dependencias externas salvo Google Fonts).
- `media/` — logo, portada, capturas del programa con datos de demostración y el comercial (`comercial.mp4`, 720p).
- `docs/` — Manual, Seguridad y Presentación en PDF.

La fuente de verdad está en el repo del producto (`TFGDESCARGASXML/marketing/landing/`); este repo es
la copia que se publica. Para actualizar: copiar la carpeta, `git commit`, `git push`.
